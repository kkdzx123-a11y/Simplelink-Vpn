## ✨ 核心功能（Key Features）

SimpleLink 致力于提供简单、直观的网络连接体验。

- **一键连接（One-Click Connection）**：开通套餐并完成授权后，可以在客户端仪表盘快速启动连接。
- **智能节点（Smart Nodes）**：支持刷新节点列表，并根据延迟选择更适合当前网络环境的线路。
- **账号管理（Account Management）**：支持用户注册、登录和账号信息管理。
- **套餐管理（Subscription Management）**：查看套餐有效期，并根据需要选择续费套餐。
- **实时网络状态（Network Status）**：在客户端仪表盘查看网络速度和连接状态。
- **在线客服（Customer Support）**：可以在客户端内联系客服，获取使用帮助。

## ⚙️ 使用指南（Getting Started）

SimpleLink 的基本使用流程分为三个步骤。

### 第一步：下载并安装

根据设备类型下载对应的 Windows 或 Android 客户端，并完成安装。

### 第二步：注册并登录

打开客户端，创建自己的账号并登录。

目前无需邀请码即可注册。

### 第三步：开通套餐并连接

1. 进入账号与套餐页面。
2. 选择适合自己的套餐。
3. 完成付款，等待授权生效。
4. 返回客户端仪表盘。
5. 刷新节点列表。
6. 根据节点延迟选择线路。
7. 点击连接按钮即可开始使用。
